# Streamlit_part_2
Данная практическая работа состоит из обязательной и факультативной частей

## Основное задание

Расширьте список городов, по которым мы получаем данные. Для этого в файле fetch_and_store.py найдите словарь CITIES и дополните его координатами других городов. Координаты можно найти в интернете.
Также уменьшите частоту запросов за данными, например раз в час. Это делается в файле weather_dag.py.

## Факультативное задание

В качестве задания повышенной сложности нужно будет сделать отображение уровня комфортности погоды. Например, если идёт дождь и стоит низкая температура, то гулять будет не очень комфортно. Будем исходить из того, что комфортная погода — это 20 градусов и без осадков.

Вывод по практической работе:

### Вывод

В ходе выполнения практической работы было разработано Streamlit-приложение для анализа погодных данных, получаемых через API и сохраняемых в базу данных SQLite. Список городов был расширен за счёт добавления новых координат в словарь `CITIES`, что позволило получать информацию по большему количеству локаций.
Также была изменена частота обновления данных в DAG-пайплайне: вместо частых запросов система настроена на запуск раз в час, что снижает нагрузку на API и делает получение данных более рациональным.
В приложении реализована визуализация погодных показателей: отображение средней температуры, количества осадков, статистики дождливых дней и таблицы последних наблюдений. Дополнительно (в рамках факультативного задания) был внедрён индекс комфортности погоды, учитывающий температуру, осадки и ветер. Это позволило оценивать, насколько погодные условия подходят для прогулок и повседневной активности.

В результате получено полноценное веб-приложение для мониторинга и анализа погодных условий с наглядными графиками, статистикой и возможностью выбора города.
