# Streamlit_part_2
Данная практическая работа состоит из обязательной и факультативной частей

""Основное задание""

Расширьте список городов, по которым мы получаем данные. Для этого в файле fetch_and_store.py найдите словарь CITIES и дополните его координатами других городов. Координаты можно найти в интернете.
Также уменьшите частоту запросов за данными, например раз в час. Это делается в файле weather_dag.py.

""Факультативное задание""

В качестве задания повышенной сложности нужно будет сделать отображение уровня комфортности погоды. Например, если идёт дождь и стоит низкая температура, то гулять будет не очень комфортно. Будем исходить из того, что комфортная погода — это 20 градусов и без осадков.
